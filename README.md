# 卡片進度簿

手機優先的信用卡回饋上限、累積消費滿額追蹤。Next.js、Vercel 與 Neon PostgreSQL。

本網站採共用帳簿模式：所有訪客都能查看、編輯、刪除同一份資料。資料庫密碼只存放在伺服器的環境變數，不會傳送到瀏覽器。

## 功能

- 卡片與活動管理；日曆月、帳單週期、季度及指定期間。
- 卡片用途可選「僅查詢優惠通路」，不顯示活動進度；同一卡片也能同時建立有限額與無上限優惠。
- 無上限回饋填入回饋率、通路與選填有效日期；空日期表示長期適用，搜尋顯示無上限，免填週期與額度。
- 消費滿額與回饋上限；直接顯示「還能刷多少／總共可刷」，3px 精簡進度條，條件備註可展開。
- 回饋上限除以回饋率換算可刷金額；實際回饋會消耗額度，零回饋率提示先設定。
- 依名稱配對官方卡面（永豐 SPORT／現金回饋 JCB、玉山 Unicard／U Bear、星展傳說對決），支援選擇卡面、自訂 HTTPS 圖片網址與簡約卡面。
- 自行上傳 JPG／PNG／WebP 卡面，原始圖片上限 15 MB，自動縮至最長 960px、300 KB 內，儲存於 Neon 並在所有裝置共用；卡面依信用卡比例裁切，可調整縮放。
- 各活動可填入優惠通路；搜尋蝦皮／Shopee 等通路列出符合的卡片、回饋與可刷金額，通路只顯示於卡片管理和搜尋頁。
- 深石墨底與柔暖白卡形圖標，統一網站標誌、16px／32px 分頁圖示、iOS 180px 主畫面圖示與 Web App manifest（192px／512px）；使用版本化圖片網址。
- 新增消費預設勾選所選卡片的所有活動；編輯保留原選擇。
- 採用「出門查一下」的中性深黑／灰色面板與低飽和鼠尾草強調色；可切換淺色，記住裝置偏好。
- 手機底部導覽、44px 觸控區與全螢幕編輯表單。
- 雲端共用資料及樂觀鎖定；發生衝突時保留表單，同步最新帳簿後再儲存，合併目前這筆修改。
- 活動總覽切換當期／全部、沿用所選卡片記帳；搜尋先顯示符合通路，長清單可展開。
- 金額以分為單位加總，可刷額向下取至兩位小數；月底、結帳日與季度邊界依活動期間裁切。
- 背景分頁與閒置兩分鐘後暫停自動讀取；使用中每分鐘同步，回到頁面時更新。

## 本機與部署

1. `npm ci`
2. 複製 `.env.example` 為 `.env.local`，填入 Neon 的 `DATABASE_URL`。
3. 執行 `node scripts/migrate.mjs` 套用 Drizzle 遷移；程式會使用直接連線，初始遷移亦相容已存在的帳簿資料表。
4. `npm run dev`；正式建置使用 `npm run build`。
5. Vercel 匯入此儲存庫，設定 `DATABASE_URL`，框架選 Next.js。

資料表結構由 `db/schema.ts` 管理。修改後使用 `npm run db:generate` 產生新的遷移檔，不覆寫已套用檔案。

所有金額為 NT$。日期與週期依 Asia/Taipei；帳單週期含結帳日，次日為新週期。查看日期用來選定週期，進度包含整個週期已記錄的消費。回饋金額依各活動比例估算；選填實際回饋時，同一金額分別採用於每個勾選的回饋活動，消費滿額不使用此欄位。

iOS：使用 Safari 開啟網站，選擇「分享 → 加入主畫面」。圖示由 imagegen 製作，原始設計提示為深色底、青綠雙層信用卡與額度進度線；網站使用同一圖標的不同尺寸。

官方卡面可依名稱配對，或按「從官網抓卡面」下載壓縮後存入雲端；來源連結記錄於 `lib/card-images.ts`。圖片失效時自動回退至簡約卡面。名稱配對不涵蓋所有卡款，可手動選擇或貼上圖片網址。
